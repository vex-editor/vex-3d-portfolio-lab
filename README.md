# VEX — Interactive 3D Portfolio (v2)

موقع بورتفوليو تفاعلي ثلاثي الأبعاد لـ **VEX — Video Editing Studio** (مونتاج ريلز).

An interactive 3D portfolio website for **VEX**, a reels/video editor. This is **v2**.

## جديد v2

- **واتساب أولاً**: زرار واتساب كبير هو التواصل الأساسي (رسالة جاهزة بتتبعت لصاحب الاستوديو)، وفورم جوجل تحته كاختيار ثاني.
- **الأعمال من جوجل شيت**: قسم الأعمال بيقرأ من شيت جوجل. أي إضافة/مسح/تعديل في الشيت يظهر على الموقع فورًا — من الموبايل، من غير كود.
- **3D تفاعلي في الموقع كله مش الخلفية بس**:
  - الكاميرا بترحل بين 5 عوالم ثلاثية الأبعاد مع الاسكرول (فريمات ريلز — كاروسيل أزرار تشغيل — مجسمات — جوهرة وعملات — عقدة وشرر).
  - سحب بالماوس/الصباع بيلف العالم الحالي.
  - الـ hover على أي مجسم 3D بينوّره ويكبّره.
  - الضغط في أي مكان بيطلّع انفجار جزيئات.
  - كروت الأعمال والأسعار عليها tilt ثلاثي الأبعاد + لمعة بتتبع الماوس، وأزرار مغناطيسية، ومؤشر مضيء.

## إدارة الأعمال من الشيت (للمالك)

الشيت: **VEX — أعمال الموقع (Works)** على Google Drive.

- تاب `works` — كل صف = عمل: العنوان | لينك الفيديو | صورة الغلاف (اختياري) | وصف قصير (اختياري).
  - لينك فيديو Google Drive أو YouTube أو mp4 مباشر.
  - أضف صف = يظهر على الموقع. امسح صف = يختفي. عدّل خلية = يتعدل. التحديث فوري عند تحميل الصفحة.
- تاب `links` — لينكات التواصل: whatsapp / facebook / instagram. حط اللينك في عمود "اللينك" وهيظهر أيقونته في الفوتر تلقائيًا. (فيسبوك وإنستجرام مخفيين لحد ما تتحط لينكاتهم.)
- الشيت متشارك "أي شخص لديه الرابط يمكنه المشاهدة" عشان الموقع يقرأه. التعديل ليك انت بس.

## التقنية (Stack)

- Static site: `index.html` + `styles.css` + `main.js` — مفيش build step.
- [Three.js](https://threejs.org) عبر CDN (import map).
- الأعمال واللينكات بتتقرأ من Google Sheets gviz JSON endpoint (الشيت مشترك للقراءة باللينك).
- Fallback: لو الشيت مردش، بتظهر نسخة محفوظة من الأعمال جوه الكود. ولو الجهاز مفيهوش WebGL أو reduced-motion متفعل، بتظهر خلفية ثابتة أنيقة.
- أداء الموبايل: جزيئات أقل، cap للـ devicePixelRatio، antialias مقفول على الموبايل، والـ tilt/magnetic مقفولين على الشاشات اللمسية.
- الخط: Cairo من Google Fonts. الموقع عربي RTL بالكامل.

## التشغيل محليًا

```bash
cd vex-3d-portfolio
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```
